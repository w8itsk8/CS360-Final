# CS360-Final

This application was created as the final assignment in CS 360: Mobile Architecture and Programming at Southern New Hampshire University. 

The app is a simple book inventory program. Full functionality is currently incomplete. As of 4/26/2026 commit, users are able to log in with seeded log-in values and view initial database. This app was designed to serve as a tool for those with collections of books to keep a record of what they have. The app has a log-in screen and a home screen where the contents of the book table are displayed. More screens to be implemented include a create new user screen and a screen for book data to be added or updated.

This app was developed using a loose Agile development method, creating minimally functionally features and testing as I went along to ensure efficacy. This was useful, as in the past I've waited until the end to de-bug and had trouble ascertaining which code was causing problems. I tested using the seeded valued included in the DatabaseHelper.java file.

The biggest struggle when creating the code for this application was the successful display of a data table much bigger than the average phone screen window. Extensive research and testing was done to ensure the multiple scroll views and sticky items to display as expected. In the end, I feel that this screen is also this more impressive and professional of the two.
